# 🗝️ Beauty Secrets

**Uma comunidade de maquiagem diversa, onde você encontra resenhas, tutoriais e novidades de influenciadoras verificadas pelas próprias marcas.**

---

## 💄 Sobre o projeto

O Beauty Secrets é um site de comunidade de maquiagem. Nele você pode consultar **resenhas, blogs e novidades** feitas por influenciadoras **verificadas pelas marcas**.

A verificação transforma a pessoa em **recomendadora oficial da marca**. Ela produz conteúdos como:

- 🎥 Vídeos divulgando os produtos
- 🌅 Makes para cada momento do dia
- 🧴 O que é cada produto e para que serve
- ✨ Como usar e qual a melhor forma de aplicar

## 🌍 Como a comunidade é organizada

A navegação segue um caminho do geral para o específico:

```
🌎 Nacionalidade (ex.: Coreia, EUA, Brasil)
 └── 🏷️ Marcas daquela região
      └── 👩 Influenciadoras por tom e tipo de pele
```

Assim, cada pessoa encontra recomendações de quem tem a pele parecida com a sua.

## 🔎 Filtros

- Nacionalidade da marca
- Marca
- Cor do produto
- Tom de pele de quem fez a resenha
- Tipo de pele: oleosa, acneica, seca, mista ou sensível
